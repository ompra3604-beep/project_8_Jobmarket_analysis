# Job Market Analysis & Recommendation System

An interactive Streamlit application for analyzing job market
trends, project budgets, hourly rates and personalized job
recommendations.

## Features

1. Interactive Job Market Dashboard
2. Job Demand Trends
3. 30-Day Demand Forecasting
4. Hourly Rate Analysis
5. Project Budget Analysis
6. AI-Based Job Recommendations
7. Country and Category Filters
8. Downloadable CSV Reports
9. Data Quality Analysis

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- TF-IDF
- Random Forest Regression

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Move into the project folder:

cd Job_Market_Analysis

Install dependencies:

pip install -r requirements.txt

## Run Application

streamlit run app.py

Open:

http://localhost:8501

## Dataset

Upload your job_market.csv file using the sidebar file uploader.

The application supports job title, country, publication date,
hourly rate, project budget and other available job information.

## Deployment

1. Upload app.py, requirements.txt and README.md to GitHub.
2. Open https://share.streamlit.io/
3. Connect your GitHub account.
4. Select your repository.
5. Select app.py as the main file.
6. Click Deploy.
